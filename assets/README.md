# Brand assets

Source files for the Ndigo visual identity.

| File                         | Purpose                                                                        |
| :--------------------------- | :----------------------------------------------------------------------------- |
| `images/Ndigo.svg`           | Primary mark — vector logo shown at the top of the [root README](../README.md) |
| `fonts/Michroma-Regular.ttf` | Michroma — display typeface used with the mark                                 |

The mark's gradient runs indigo → violet: `#293896` → `#5B3BE0` → `#9A38FF`.
