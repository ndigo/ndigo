# Function: product()

> **product**(`list`): `number`

Multiplies together all the elements of a list.

## Parameters

### list

`number`[]

An array of numbers

## Returns

`number`

The product of all the numbers in the list.

## See

`reduce`

## Example

```ts
product( [ 2, 4, 6, 8, 100, 1 ] );
//=> 38400
```
