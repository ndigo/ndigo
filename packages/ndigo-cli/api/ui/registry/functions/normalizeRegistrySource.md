# Function: normalizeRegistrySource()

> **normalizeRegistrySource**(`source`): `string`

Normalizes a registry source: relative paths become absolute, and a
directory resolves to its `registry.json`.

## Parameters

### source

`string`

Registry file, directory, or URL.

## Returns

`string`

The normalized source.
