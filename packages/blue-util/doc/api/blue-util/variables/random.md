# Variable: random

> `const` **random**: () => `number`

Generates a pseudo-random number.

## Returns

`number`

A pseudo-random number between `0` and `1`.

## Example

```ts
random();
//=> 0.9282578795792454
random();
//=> 0.3752569768646784
```
