# Function: removeTheme()

> **removeTheme**(`target?`): `void`

Removes an applied theme from `target`, clearing inline overrides and the
theme attributes.

## Parameters

### target?

[`ThemeTarget`](../type-aliases/ThemeTarget.md)

Element to clear. Defaults to the document root.

## Returns

`void`
