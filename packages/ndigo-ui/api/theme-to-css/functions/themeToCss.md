# Function: themeToCss()

> **themeToCss**(`theme`, `selector?`): `string`

Builds a CSS rule that applies a theme's token overrides to `selector`.

## Parameters

### theme

[`Theme`](../../theme/interfaces/Theme.md)

Theme to serialize.

### selector?

`string` = `':root'`

CSS selector to target. Defaults to `:root`.

## Returns

`string`

CSS text.
