# Function: isConstructor()

> **isConstructor**(`value`): `value is Function`

Determines whether a given value is a constructor, i.e. creates instances using `new`.

## Parameters

### value

`unknown`

The value to be tested.

## Returns

`value is Function`

Whether or not `value` is a constructor.
