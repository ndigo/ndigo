# Function: toPascal()

> **toPascal**(`value`): `string`

Returns the PascalCase version of a string.

## Parameters

### value

`string`

The input string.

## Returns

`string`

The PascalCase version.

## Example

```ts
toPascal('lorem-ipsum-dolor'); //=> "LoremIpsumDolor"
```
