# Function: likeView()

> **likeView**(`value`): `value is View`

Tests whether a value behaves like a [View](../interfaces/View.md): an object exposing a
`render` function and a `mediaType`.

## Parameters

### value

`unknown`

The value to inspect.

## Returns

`value is View`

`true` when the value is View-shaped.
