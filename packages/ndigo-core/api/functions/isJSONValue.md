# Function: isJSONValue()

> **isJSONValue**(`value`): `value is JSONValue`

Tests whether a value is directly representable in JSON.

## Parameters

### value

`unknown`

Value to test.

## Returns

`value is JSONValue`

`true` for JSON primitives, arrays, objects, and `null`.
