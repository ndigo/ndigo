# Ndigo UI Storybook

Storybook for the Ndigo UI registry components. Documents the canonical
registry source under `packages/ndigo-ui/registry`.

## Demonstrates

- Interactive showcase of the 42-item `@ndigo/ui` registry
- Tokens, native-first primitives, Zag.js behaviour elements, blocks
- Storybook catalog of the canonical registry source under
  `packages/ndigo-ui/registry`

## Development

```bash
pnpm storybook
```

## Build

```bash
pnpm build:storybook
```
