    Class BlueLoggerProvider

    BlueLoggerProvider wraps OpenTelemetry's LoggerProvider to provide blue-logger conventions and backward compatibility with the Appender system.

    Example

    import { BlueLoggerProvider, ConsoleExporter } from '@blue/logger';

    const provider = new BlueLoggerProvider({
      processors: [
        new SimpleLogRecordProcessor(new ConsoleExporter())
      ]
    });

    const logger = provider.getLogger('my-app');
    logger.info('Application started');

    • fromAppenders(
          appenders: Appender[],
          config?: Omit<BlueLoggerProviderConfig, "processors">,
      ): BlueLoggerProvider

      Create a BlueLoggerProvider with Appender-based processors (backward compatibility)

      This static factory method allows existing code using Appenders to work with the new OTel architecture. Each Appender is wrapped in an AppenderLogRecordExporter.

      NOTE: In OpenTelemetry SDK v0.211.0, processors must be configured at construction time. If you need to use appenders, create a provider with this method.

      Parameters

      • appenders: Appender[]

        Array of blue-logger Appenders

      • config: Omit<BlueLoggerProviderConfig, "processors"> = {}

        Optional provider configuration

      Returns BlueLoggerProvider

      BlueLoggerProvider configured with appenders

      Example

      import { ConsoleAppender } from '@blue/logger';

      const provider = BlueLoggerProvider.fromAppenders([
        new ConsoleAppender()
      ]);
      const logger = provider.createLogger('my-app');
