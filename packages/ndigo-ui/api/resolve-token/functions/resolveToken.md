# Function: resolveToken()

> **resolveToken**(`name`, `fallback?`): `string`

Builds a `var()` reference for a token, optionally with a fallback.

## Parameters

### name

`` `--nd-${string}` ``

Token to reference.

### fallback?

`string`

Value used when the custom property is unset.

## Returns

`string`

A CSS `var()` expression.
