# @blue/generators

Code generation utilities and project scaffolding for BlueJS. Provides Nx-compatible generators for bootstrapping new packages, components, and configurations.

## Installation

```bash
pnpm add @blue/generators
```

## Usage

These generators are designed to work with Nx's code generation system. They can be invoked via the Nx CLI or programmatically.

```bash
nx generate @blue/generators:package my-package
```
