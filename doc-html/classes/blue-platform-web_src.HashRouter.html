    Class HashRouter

    A hash-based router implementation for browser environments that extends AbstractRouter. It manages routing based on the URL hash fragment, supports route interceptors, and maintains a route history. This class structurally conforms to the Destroyable shape (destroyed + destroy()) without importing the interface, so likeDestroyable checks can still identify it by duck typing.
