    Class InMemoryUnitOfWork

    An in-memory implementation of the UnitOfWork interface. Tracks new, dirty, and removed entities and flushes changes via an EntityManager.

    Use this class in tests or with InMemoryEntityManager. For SQL-backed stores, implement UnitOfWork with your EntityManager adapter.
