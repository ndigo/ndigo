# Function: randInt()

> **randInt**(`min?`, `max?`): `number`

Generates a pseudo-random integer between `min` and `max`.

## Parameters

### min?

`number`

### max?

`number`

## Returns

`number`

A pseudo-random integer between `min` and `max`.

## Example

```ts
randInt( 0, 10 );
//=> 7
randInt( 0, 10 );
//=> 6
```
