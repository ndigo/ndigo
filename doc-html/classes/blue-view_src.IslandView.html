    Class IslandView

    A server-rendered HTML view for partial hydration ("islands").

    Renders an inert custom-element marker carrying the serialized view model:

    <my-element data-blue-island data-blue-model="&quot;{...}&quot;"></my-element>

    It is fully server-safe (no customElements, no DOM, no component-module import): it serializes only the model into markup. On the client, hydrateIslands() (from @blue/view-webcomponent) finds the marker, constructs the element, sets .model, and lets connectedCallback run.

    Example

    return new ModelAndView(new IslandView('todo-app'), { items: [...], filter: 'all' });
