# Function: hasCounted()

> **hasCounted**(`target`, `propertyKey`): `boolean`

Checks if a method has been decorated with `counted`.

## Parameters

### target

`object`

The target object or prototype.

### propertyKey

`string` \| `symbol`

The name of the method.

## Returns

`boolean`

`true` if the method is counted, otherwise `false`.
