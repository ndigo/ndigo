# Function: sum()

> **sum**(`list`): `number`

Adds together all the elements of a list.

## Parameters

### list

`number`[]

An array of numbers

## Returns

`number`

The sum of all the numbers in the list.

## See

`reduce`

## Example

```ts
sum( [ 2, 4, 6, 8, 100, 1 ] );
//=> 121
```
