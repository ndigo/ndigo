# Function: isActiveForCurrentPlatform()

> **isActiveForCurrentPlatform**(`target`): `boolean`

Checks whether a class can run in the current environment (platform only).

## Parameters

### target

`unknown`

The class constructor or instance to check.

## Returns

`boolean`

`true` when the class should be registered in this environment.
