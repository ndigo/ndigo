# Function: subtract()

> **subtract**(`a`, `b`): `number`

Subtracts its second argument from its first argument.

## Parameters

### a

`number`

The first value.

### b

`number`

The second value.

## Returns

`number`

The result of `a - b`.

## See

[add](add.md)

## Example

```ts
subtract( 10, 8 );
//=> 2
subtract( 90, 30 );
//=> 60
```
