# Variable: isJSONArray

> `const` **isJSONArray**: (`value`) => `value is JSONArray`

Tests whether a value is a JSON array.

## Parameters

### value

`unknown`

Value to test.

## Returns

`value is JSONArray`

`true` when the value is an array that survives a JSON round trip unchanged.
