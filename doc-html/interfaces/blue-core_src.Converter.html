    Interface Converter<S, T>

    A general-purpose type conversion from source S to target T.

    Unlike Parser (string → T) and Stringifier (T → string), this interface handles arbitrary source-to-target conversions. It is the class-based form used by ConverterRegistry and ConversionService.

    For simple one-off conversions, use a plain function typed as Converter<S, T> directly — the registry accepts any object with a convert method:

    Example

    // Class-based converter (for registration)
    class MyIdConverter implements Converter<string, MyId> {
        convert(value: string): MyId { return new MyId(value); }
    }
    registry.register(new MyIdConverter(), String, MyId);

    // Function-based converter (directly usable)
    const parseHex: Converter<string, number> = (s) => parseInt(s, 16);
    interface Converter<S, T> {
        convert(source: S): T;
    }
