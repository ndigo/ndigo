# Function: divide()

> **divide**(`a`, `b`): `number`

Divides two numbers. Equivalent to `a / b`.

## Parameters

### a

`number`

The first value.

### b

`number`

The second value.

## Returns

`number`

The result of `a / b`.

## See

[multiply](multiply.md)

## Example

```ts
divide( 71, 100 ); //=> 0.71
divide( 1, 4 );    //=> 0.25
```
