# Function: multiply()

> **multiply**(`a`, `b`): `number`

Multiplies two numbers. Equivalent to `a * b`.

## Parameters

### a

`number`

The first value.

### b

`number`

The second value.

## Returns

`number`

The result of `a * b`.

## See

[divide](divide.md)

## Example

```ts
multiply( 2, 5 );
//=> 10
multiply( 3, 4 );
//=> 12
```
