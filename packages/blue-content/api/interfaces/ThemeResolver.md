## Methods

### getTheme()

> **getTheme**(`name?`): [`Theme`](Theme.md)

Gets a theme by name, or the default theme when no name is provided.

#### Parameters

##### name?

`string`

Optional theme name.

#### Returns

[`Theme`](Theme.md)

The resolved theme.
