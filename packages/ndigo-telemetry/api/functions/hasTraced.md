# Function: hasTraced()

> **hasTraced**(`target`, `propertyKey`): `boolean`

Checks if a method has been decorated with the `traced` decorator.

## Parameters

### target

`object`

The target object or prototype.

### propertyKey

`string` \| `symbol`

The name of the method.

## Returns

`boolean`

`true` if the method is traced, otherwise `false`.
