    Class LocalStorageResourceLoader

    Resource loader that persists data to localStorage.

    Provides a simple key-value storage adapter backed by the browser's localStorage API. Useful for caching user preferences, theme selections, or small amounts of data that should survive page reloads.

    Example

    const storage = new LocalStorageResourceLoader('my-app');
    storage.setItem('theme', 'dark');
    const theme = storage.getItem('theme'); // 'dark'
