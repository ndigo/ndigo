    mountLazy

    • mountLazy(name: string): Promise<FeatureContextComposition>

      Mount a feature whose context is loaded dynamically via its registered loader.

      For features registered with a static createContext, use mount instead.

      If the feature has already been loaded and mounted, returns the existing composition. If a load is already in progress, awaits that same promise (deduplication). Failed loads are retried on the next call — the error state is cleared.

      Parameters

      • name: string

        The registered feature name.

      Returns Promise<FeatureContextComposition>

      A promise resolving to the feature context composition.

      Throws

      If the feature has no loader registered.

      Throws

      If the loader rejects or createContext throws.
