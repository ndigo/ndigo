# Variable: CACHED\_METADATA\_PREFIX

> `const` **CACHED\_METADATA\_PREFIX**: `"cache:"` = `'cache:'`

Metadata key prefix under which `@cached` writes its per-method spec —
`cache:<methodName>` (mirror of `@scheduled`'s `schedule:` prefix).
