# Function: isJSONObject()

> **isJSONObject**(`value`): `value is JSONObject`

Tests whether a value is a JSON object.

## Parameters

### value

`unknown`

Value to test.

## Returns

`value is JSONObject`

`true` when the value is a non-primitive, non-array object that survives a JSON round trip unchanged.
