# Package Map

The hand-maintained package reference: purpose, layer, platform, and declared
Ndigo runtime dependencies. The public, generated inventory lives at
[Reference → Packages](https://ndigo.dev/reference/packages/); this table adds
the layer and platform view that the manifests cannot express.

Repo-only tooling lives outside `packages/`: the internal lint rules in root
`src/oxlint/`, the Nx generator collection in `tools/generators/`, and
one-shot probes in `scripts/`.

**Standalone use:** every package resolves its own install closure — once
published, `npm install @ndigo/http` will pull exactly `core`, `factory`,
`util`, and its external dependencies. `peerDependencies` is allowlisted per
package for host-provided contracts (`oxlint-plugin → oxlint`,
`telemetry-node → ws`, `platform-node → swagger-ui-dist`,
`boot → @toon-format/toon`, `flags-openfeature → @openfeature/server-sdk`,
`redis → cache`/`factory`/`jobs`/`locks`/`rate-limit`/`socket`).
