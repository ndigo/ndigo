# BlueJS Documentation

This directory contains all project documentation organized by category.

## Categories

### [Migrations](./migrations/)

Breaking changes and upgrade guides for major transitions.

### [Plans](./plans/)

Implementation plans for features and technical specifications.

### [Reference](./reference/)

Technical references, specifications, and dependency documentation.

### [Audits](./audits/)

Codebase analysis, compliance reports, and improvement tracking.

## Naming Convention

All documentation files follow the format: `YYYY-MM-DD_DESCRIPTION.md`

Where:

- `YYYY-MM-DD` - ISO 8601 date (creation or last major update)
- `_` - Underscore separator
- `DESCRIPTION` - Brief description in ALL_CAPS with underscores for multi-word phrases
